# [Proyecto 1 : Clasificador de partículas](https://github.com/lauriesme09/Magic_Proj)
- Se construye un clasificador que distingue dos tipos de partículas, gamma y hadrón, a partir de 10 variables numéricas registradas por el telescopio MAGIC (dataset de UCI).
- Se estandarizan y balancean las clases mediante sobremuestreo aleatorio solo para el conjunto de entrenamiento.
- Se comparan dos modelos: Regresión Logística y Random Forest.
